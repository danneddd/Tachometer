Arduino-Based Digital Speedometer
As part of my HTL diploma project, I developed a digital speedometer for an electric tricycle (E-Trike) using an Arduino UNO.
The system measures wheel rotations through a reed switch and magnet, calculates the vehicle's speed in real time, and displays it on a 16×2 LCD.

Technical Features
-Arduino UNO microcontroller
-Reed switch for wheel rotation detection
-Real-time speed calculation (km/h)
-16×2 LCD for speed visualization

Software debouncing (20 ms) for reliable measurements
Wheel diameter: 500 mm

Technologies: Arduino, C/C++, Embedded Systems, Sensor Technology
